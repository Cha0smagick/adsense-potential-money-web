Política de privacidad

Última actualización: 24 de noviembre de 2026. Responsable: Cha0sMagick Labs · magiadelcaospractica@gmail.com.

Qué datos se procesan

El auditor no tiene backend propio, ni cuentas, ni base de datos. Todo el análisis se ejecuta en tu navegador. Los datos que introduces son:

  • La URL que decides auditar.
  • Sesiones/mes, nicho, país, porcentaje móvil, RPM y CTR, si los aportas.
  • Tu API key de PageSpeed y, si usas el motor profundo, el repositorio y el token de GitHub.

Se guardan en el localStorage de tu navegador para no tener que reescribirlos. No se envían a ningún servidor nuestro. Puedes borrarlos con el botón «Limpiar» o borrando los datos del sitio en tu navegador.

Qué terceros intervienen

Para leer el sitio auditado y obtener datos públicos, el navegador hace peticiones directas a servicios externos. Cada uno recibe la URL o el dominio consultado y tu dirección IP, como en cualquier petición web:

El token de GitHub se guarda solo en tu navegador y se usa para lanzar el workflow que tú elijas. No lo recibimos nosotros.

Cookies

La herramienta no instala cookies propias. Usa localStorage para recordar tus ajustes. Si en el futuro se activan anuncios de Google en este sitio, se mostrará un aviso de consentimiento certificado y la política se actualizará antes de servir publicidad personalizada en el EEE, Reino Unido o Suiza.

Conservación y derechos

No conservamos datos en servidores. Los ajustes viven en tu navegador hasta que los borres. Para ejercer acceso, rectificación, supresión u oposición sobre cualquier dato que nos hayas enviado por correo, escribe a magiadelcaospractica@gmail.com.

Base jurídica: interés legítimo en responder a tu consulta y, cuando corresponda, tu consentimiento. No se elaboran perfiles ni se venden datos.

Menores

La herramienta no está dirigida a menores de 14 años y no recoge datos de forma consciente de menores.

Cambios

Si cambia el tratamiento de datos, se actualizará esta página con la fecha. El uso continuado después del cambio implica aceptación de la versión vigente.
